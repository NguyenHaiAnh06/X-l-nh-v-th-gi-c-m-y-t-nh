# Image Processing & Computer Vision

Repository này tổng hợp kiến thức, thuật toán, bài thực hành và các dự án liên quan đến **Xử lý ảnh (Image Processing)** và **Thị giác máy tính (Computer Vision)**. Mục tiêu là xây dựng nền tảng từ các phép xử lý ảnh cơ bản đến các ứng dụng nhận diện và phân tích hình ảnh bằng AI.

## 🎯 Mục tiêu

- Nắm vững các khái niệm cơ bản về ảnh số và xử lý ảnh.
- Sử dụng Python, NumPy và OpenCV để thao tác với hình ảnh.
- Hiểu các thuật toán xử lý ảnh truyền thống.
- Tìm hiểu các phương pháp phát hiện, phân loại và nhận diện đối tượng.
- Tiếp cận Computer Vision kết hợp Machine Learning và Deep Learning.
- Xây dựng các dự án thực tế phục vụ học tập và nghiên cứu.

## 🧠 Lộ trình học tập

### 1. Mathematics for Computer Vision

Các kiến thức toán học hỗ trợ việc hiểu và triển khai thuật toán:

- Linear Algebra: vector, ma trận, phép biến đổi tuyến tính.
- Calculus: đạo hàm, gradient và các khái niệm tối ưu hóa.
- Probability & Statistics: xác suất, phân phối và thống kê.
- Geometry: hệ tọa độ, phép biến đổi hình học và không gian 3D.

### 2. Digital Image Processing

Tìm hiểu cách biểu diễn và biến đổi ảnh số.

- Image representation: pixel, độ phân giải, RGB, BGR, Grayscale.
- Image operations: đọc, ghi, hiển thị và cắt ảnh.
- Color spaces: RGB, HSV, LAB.
- Image enhancement: điều chỉnh độ sáng, độ tương phản và histogram.
- Image filtering: Gaussian Blur, Median Blur, Bilateral Filter.
- Edge detection: Sobel, Laplacian, Canny.
- Thresholding: nhị phân hóa ảnh và Adaptive Thresholding.
- Morphological operations: Erosion, Dilation, Opening, Closing.
- Geometric transformations: Resize, Rotation, Translation, Affine Transformation.
- Image segmentation: phân vùng ảnh và tách đối tượng.

### 3. Computer Vision Fundamentals

Tìm hiểu cách máy tính phân tích và hiểu nội dung hình ảnh.

- Feature detection and description.
- Contour detection và shape analysis.
- Object tracking.
- Camera calibration.
- Image stitching và panorama.
- Optical flow.
- Motion detection.
- Stereo vision và ước lượng độ sâu.

### 4. Machine Learning for Computer Vision

Ứng dụng Machine Learning vào dữ liệu hình ảnh.

- Data preprocessing và feature extraction.
- Image classification.
- K-Nearest Neighbors (KNN).
- Support Vector Machine (SVM).
- Model evaluation và confusion matrix.
- Training, validation và testing datasets.

### 5. Deep Learning for Computer Vision

Tìm hiểu các mô hình học sâu hiện đại.

- Neural Networks và Convolutional Neural Networks (CNN).
- Image classification.
- Object detection.
- Semantic segmentation và instance segmentation.
- Transfer learning.
- Face detection và face recognition.
- Các mô hình và công cụ như YOLO, PyTorch và TensorFlow.
